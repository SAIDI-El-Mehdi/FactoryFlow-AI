# 🤖 FactoryFlow AI - Intelligent Manufacturing Dashboard

A smart industrial automation dashboard designed to monitor robot status, manage task queues, and visualize real-time manufacturing simulations.

### ✨ Key Features

*   📊 **Live Analytics:** Real-time monitoring of performance metrics and production efficiency.
*   🤖 **Robot Status:** Instant tracking of robotic arm availability, workload, and current tasks.
*   📋 **Intelligent Task Queue:** Automated scheduling of assembly and painting tasks with priority levels.
*   🌐 **Webots Integration:** Seamless visualization of industrial simulation processes directly within the dashboard.
